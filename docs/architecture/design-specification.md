# Family Messenger — Спецификация дизайн-системы «Hearth & Nordic Linen»

## 1. Философия дизайна (Human-Quality / Anti-AI-Slop)

Визуальный язык **Family Messenger** спроектирован специально для приватного семейного общения — тёплый, тактильный, спокойный и редакционный (Editorial).
Мы сознательно отказываемся от:
- неоново-фиолетовых градиентов и шаблонных AI-карточек;
- визуального копирования экранов Telegram (синие пузыри и перегруженные тулбары), WhatsApp (зелёный хедер) или Element (технический корпоративный интерфейс);
- неработающих декоративных иконок и кнопок-пустышек: **каждый элемент на экране подключён к реальному действию**.

## 2. Цветовая палитра (Light & Dark Themes)

### Светлая тема — *Nordic Linen*
- **Canvas Background (`surface`)**: `#F7F4EF` (тёплый неотбелённый лён, снижает нагрузку на глаза).
- **Elevated Panel (`surfaceContainer`)**: `#EFECE6` (мягкий известняк для боковой панели и карточек).
- **Primary Accent (`primary`)**: `#2A5C4A` (глубокий хвойный изумруд — символ доверия и защищённости).
- **Secondary Accent (`secondary`)**: `#B86B43` (терракотовый акцент для статусов и семейных меток).
- **Outgoing Message Surface**: `#2A5C4A` с текстом `#F9F7F3`.
- **Incoming Message Surface**: `#FFFFFF` с тонкой рамкой `#E4DFD7` и текстом `#1C201E`.
- **E2EE Verified Badge**: `#246A4E` (фон `#DFF0E8`).
- **Warning / Unverified / Offline Banner**: `#9A4B26` (фон `#FBE9DF`).

### Тёмная тема — *Evening Hearth*
- **Canvas Background (`surface`)**: `#121615` (глубокий графитово-хвойный).
- **Elevated Panel (`surfaceContainer`)**: `#1A201E` (тёмный сланец).
- **Primary Accent (`primary`)**: `#63B999` (мягкий шалфей).
- **Secondary Accent (`secondary`)**: `#E09167` (тёплый янтарь).
- **Outgoing Message Surface**: `#21483A` с текстом `#ECF4F0`.
- **Incoming Message Surface**: `#1D2421` с рамкой `#2B3531` и текстом `#E6ECE9`.

## 3. Типографика и модульная сетка

- **Базовый шаг сетки**: `4px` (`xs: 4`, `sm: 8`, `md: 12`, `lg: 16`, `xl: 24`, `xxl: 32`).
- **Иерархия шрифтов**:
  - Заголовки разделов и комнат: полужирный гротеск с плотным трекингом (`letterSpacing: -0.3`, `fontWeight: w600`).
  - Текст сообщений: `15px`, комфортный интерлиньяж `height: 1.42` для длительного чтения на мобильных экранах.
  - Криптографические отпечатки (Device Keys, Event IDs, Recovery Keys): моноширинный шрифт (`Consolas` / `Roboto Mono`, `12.5px`) с группировкой по 4 символа.

---

## 4. Адаптивная компоновка (Android / Windows / iOS)

- **Широкий экран (`width >= 760px`, Windows Desktop / планшеты)**:
  - Двухпанельный **Split-View**:
    - Левая колонка (`340px`): заголовок с индикатором состояния соединения и E2EE, кнопки создания зашифрованной комнаты и управления ключами E2EE, список переписок с живыми превью.
    - Правая панель: заголовок активной комнаты с верифицированным статусом `m.megolm.v1.aes-sha2`, лента сообщений с группировкой по отправителю и времени, поле ввода и отправки.
- **Компактный экран (`width < 760px`, Android / iOS)**:
  - Однопанельный режим с плавным переходом между списком комнат и экраном активной переписки.
- **Баннер состояния сети**:
  - При потере связи с сервером автоматически появляется ненавязчивый индикатор *«Нет связи с сервером — работа из локального кеша, автоповтор...»*, который скрывается сразу после восстановления синхронизации.
